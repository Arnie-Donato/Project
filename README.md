# Arnie Systems Landing Page

A responsive, GitHub Pages-ready landing page.

## Google Calendar
The booking CTAs now scroll to an embedded Google Calendar appointment scheduler using the iframe embed supplied for this site.

## Publish on GitHub Pages
1. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
2. Go to Settings → Pages.
3. Choose Deploy from branch → `main` → `/ (root)`.
4. Save and open the generated GitHub Pages URL.

Replace sample metrics, testimonial, and branding before publishing publicly.
