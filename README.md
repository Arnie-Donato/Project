# Arnie Systems Landing Page

A responsive, GitHub Pages-ready landing page based on the approved visual direction.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to Settings → Pages.
4. Choose Deploy from branch → main → / (root).
5. Save and open the generated GitHub Pages URL.

Replace sample metrics, testimonial, email, and branding before publishing publicly.
